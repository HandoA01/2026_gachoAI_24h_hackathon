# 가천 코인 (Gachon Coin) - 프로젝트 개요

가천대학교 학생들을 위한 **코인 기반 스터디/프로젝트 매칭 커뮤니티** 모바일 웹앱입니다. 사용자는 게시물을 통해 팀원을 모집하고, 모집글 작성자가 역할별로 가천 코인을 분배합니다. 참여자는 활동을 통해 코인을 획득하고 전문가 타이틀을 쌓아갑니다.

## 핵심 기능

1. **인증**: 가천대 이메일(`@gachon.ac.kr`) 기반 회원가입 + 인증번호 검증
2. **게시물**: 스터디/프로젝트 모집글 작성, 역할별 코인 분배, 태그 분류
3. **참여**: 참가/탈퇴, 댓글, 전문가 추천(초대) 기능
4. **상태 관리**: 모집중 / 완료 / 반려 / 취소
5. **프로필**: 보유 코인, 관심 태그, 전문가 타이틀(다중)

## 타겟

- **사용자**: 가천대학교 재학생
- **플랫폼**: 모바일 웹 (max-width 390px)
- **기술 스택**: React 19 + TypeScript + Tailwind v4 + React Router + Zustand + Axios
