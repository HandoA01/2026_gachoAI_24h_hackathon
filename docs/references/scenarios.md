# 사용자 시나리오 (Scenarios)

본 문서는 가천 코인 시스템에서 발생하는 핵심 사용자 흐름과 비즈니스 규칙을 정의합니다.

## 1. 회원가입 시나리오 (Sign Up Flow)

**대상**: 가천대학교 재학생만 가입 가능

### 흐름
1. **Step 1 - 이메일 입력**: 사용자가 가천대 이메일(`@gachon.ac.kr`) 입력 → "인증번호 전송" 버튼 클릭
2. **인증번호 발송**: 백엔드가 해당 이메일로 6자리 인증번호 발송 (유효시간 5분)
3. **인증번호 입력**: 같은 화면에 인증번호 입력 필드 노출 → 입력 후 "확인" 버튼
4. **Step 2 - 정보 입력**: ID, 이름, 비밀번호 입력 → "회원가입 완료"
5. **자동 로그인 후 메인 페이지 이동**

### 검증 규칙
- 이메일: `@gachon.ac.kr` 도메인만 허용
- 인증번호: 6자리 숫자, 5분 내 유효
- ID: 4~20자 영문/숫자
- 비밀번호: 8자 이상, 영문+숫자+특수문자 1개 이상씩 포함

## 2. 로그인 시나리오 (Login Flow)

### 흐름
1. ID + 비밀번호 입력
2. "로그인" 버튼 클릭
3. 성공 시 메인 페이지 이동, JWT를 클라이언트에 저장 (`localStorage` 또는 `zustand persist`)
4. 실패 시 에러 메시지 ("ID 또는 비밀번호가 올바르지 않습니다")

## 3. 게시물 생성 시나리오 (Post Creation)

### 흐름
1. 메인 페이지 우하단 FAB 또는 상단 + 버튼 클릭 → 생성 페이지 이동
2. 입력 필드
   - 제목, 본문
   - 태그 선택 (다중 선택, Physics/Chemistry/Maths/Programming/Language 등)
   - 모집 역할 추가 (역할명 + 모집 인원 + 할당 코인)
   - 마감일 설정
3. "등록" 클릭 시 게시물 생성 → 상세 페이지로 이동

### 코인 분배 규칙
- 게시물 작성 시 작성자는 **총 할당 코인 = 역할별 코인 × 인원의 합** 만큼 보유 코인에서 차감
- 보유 코인 부족 시 등록 불가 (에러 토스트 노출)
- 게시물이 **완료** 상태가 되면 참여자에게 코인 자동 지급
- 게시물이 **반려/취소** 상태가 되면 작성자에게 코인 환불

## 4. 게시물 참여 시나리오 (Join Flow)

### 흐름
1. 게시물 상세 페이지에서 원하는 역할의 "참여하기" 버튼 클릭
2. 작성자가 참여 신청을 확인 후 승인/거절
3. 승인 시 해당 역할에 등록 (모집 인원에 1명 추가)
4. 모집 인원이 다 차면 해당 역할 자동 마감

### 탈퇴 규칙
- 게시물이 **완료** 처리되기 전에는 언제든 탈퇴 가능
- 탈퇴 시 작성자에게 알림

## 5. 게시물 상태 변경 시나리오

| 상태 | 설명 | 코인 처리 |
| :--- | :--- | :--- |
| **모집중** | 모집 인원이 다 차지 않은 상태 | 작성자 보유 코인에서 차감 (예치) |
| **완료** | 작성자가 활동 종료 후 완료 처리 | 참여자에게 코인 지급 |
| **반려** | 운영진에 의한 부적절 게시물 처리 | 작성자에게 코인 환불 |
| **취소** | 작성자가 직접 취소 | 작성자에게 코인 환불 |

## 6. 전문가 추천 시나리오 (Expert Invitation)

### 흐름
1. 게시물 작성자가 상세 페이지에서 "전문가 추천" 버튼 클릭
2. 시스템이 해당 태그의 전문가 타이틀을 가진 유저 추천 (Top 5)
3. 작성자가 추천 유저에게 초대 알림 전송
4. 초대받은 유저는 알림 확인 후 참여 가능

## 7. 댓글 시나리오 (Comment)

- 게시물 상세 페이지에서 댓글 작성 가능
- 작성자/참여자/일반 유저 모두 댓글 작성 가능
- 댓글 삭제는 본인 또는 작성자만 가능
- 대댓글은 1단계까지만 지원 (depth=1)
